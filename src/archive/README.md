# Archived experiments

Former experiment scripts kept here for reference (not part of the main pipeline).
The supported entry point is `src/main.py` (calibrated MobileCLIP-S0 zero-shot).

These files still import as if they lived under `src/`; to re-run one, either
move it back or run with `PYTHONPATH=src:src/archive` and adjust imports.

See `docs/experiments.md` for results from these runs.
